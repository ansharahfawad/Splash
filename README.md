# Splashes Website

A responsive website built for **Splashes**, a children's swimming lesson business, as part of the Westcliff University Full Stack Coding Bootcamp (Project 1).

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES5)
- jQuery + Ajax
- Bootstrap 4
- Vue.js

## Features
- 8 responsive pages (home, about, classes, schedule, pricing, instructors, contact, register)
- Register/Sign-in modal available from every page nav
- HTML table (class schedule) and HTML form (register/contact)
- Ajax-loaded testimonials section (jQuery, home page)
- jQuery FAQ accordion (about page)
- Client-side form validation on all forms
- Vue.js interactive class filter (classes page)
- Responsive layout tested at mobile, tablet, and desktop breakpoints

## How to Run
No build step required. Clone the repo and open `index.html` directly in a browser:
```bash
git clone https://github.com/ansharahfawad/Splash.git
cd Splash
```
Then open `index.html` in any modern browser.

## Notes
- Images use placeholder paths (`images/placeholder-*.jpg`) in place of final client-provided media assets.
- Built and tested solo (no assigned team) across Chrome, Firefox, and Edge.
